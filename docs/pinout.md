# K7-160T-DP ピン配置

FPGAのパッケージピン名(例: C21)、基板の部品番号(例: LED D5、コネクタ J4)、テストポイント番号(TP)は互いに別物。
表記は「TP番号 (FPGAピン)」で統一する。

## クロック・LED・UART

| 信号 | FPGAピン | バンク | IOSTANDARD | 状態 |
|---|---|---|---|---|
| clk 50MHz | D24 (`IO_L11N_T1_SRCC_14`) | 14 | LVCMOS33 | 実機確認済み。基板の発振器 Y2 (50.000MHz) |
| LED D5 | C21 | 14 | LVCMOS33 | 実機確認済み。Highで点灯するかLowで点灯するかは未記録 |
| UART TX | TP3 (V23) | 12 | LVCMOS33 | 実機確認済み(シルク表記なし、空きTPを流用) |
| UART RX | TP4 (U22) | 12 | LVCMOS33 | 実機確認済み |

- **D24はSRCC差動ペアのN側**で、P側のD23に発振器はつながっていない。シングルエンドで使うため、Vivadoでは `CLOCK_DEDICATED_ROUTE FALSE` が必要(付けないとDRCの `PLIO-9` で弾かれる)。
- **TP22 (D23) は使用禁止扱い。** クロックピンD24の差動ペアの相方にあたる。汎用出力として駆動した構成で、ボードがUARTに何も出さなくなった事例がある(原因は未確定。テスト時のポート取り違えの可能性も残る)。
- UARTはボード側TX→アダプタRXD、ボード側RX→アダプタTXDのクロス接続にし、GNDも共通にする。3.3Vのアダプタで動作した。

## GPIO(テストポイント 57点)

## DDR3

Samsung K4B2G1646F-BCK0 ×2、Bank 33/34。IOSTANDARDは出荷時ビットストリームの解析で確定した値(DCIなし)。ベンダー資料にある `SSTL15_T_DCI` / `LVCMOS15` は誤り。

| 信号 | FPGAピン | IOSTANDARD |
|---|---|---|
| dq[0:7] | AA4 AB4 AC4 AC3 AC6 Y6 Y5 AD6 | SSTL15 |
| dq[8:15] | AD1 AE1 AE3 AE2 AE6 AE5 AF3 AF2 | SSTL15 |
| dq[16:23] | U5 U2 U1 V3 W3 U7 V6 V4 | SSTL15 |
| dq[24:31] | Y2 V2 V1 W1 Y1 AB2 AC2 AA3 | SSTL15 |
| dqs_p[0:3] | AA5 AF5 W6 AB1 | DIFF_SSTL15 |
| dqs_n[0:3] | AB5 AF4 W5 AC1 | DIFF_SSTL15 |
| dm[0:3] | AB6 AD4 U6 Y3 | SSTL15 |
| addr[0:7] | AA7 AA8 AF7 AE7 W8 V9 Y10 Y11 | SSTL15 |
| addr[8:13] | Y7 Y8 V7 V8 W11 V11 | SSTL15 |
| ba[0:2] | AB7 AD8 AC8 | SSTL15 |
| ck_p / ck_n | W10 / W9 | DIFF_SSTL15 |
| ras_n / cas_n / we_n | AC7 / AA9 / AB9 | SSTL15 |
| cs_n / cke / odt | AC9 / AB12 / AC12 | SSTL15 |
| reset_n | AA2 | SSTL15 |

- バイトレーン: レーン0 = dq[7:0]/dqs[0]/dm[0]、レーン1 = dq[15:8]、レーン2 = dq[23:16]、レーン3 = dq[31:24]。チップ1がレーン0/1、チップ2がレーン2/3。
- DQSピンはMRCC/SRCCではないため、DQSをBUFIOに載せる構成(DQSで直接キャプチャする方式)はこの配線では作れない。詳細は [ddr3.md](ddr3.md)。
