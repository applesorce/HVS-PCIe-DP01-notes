# HVS PCIe-DP01 (K7-160T-DP) ボード概要

ボード名は **HVS PCIe-DP01**(HYVISION SYSTEM製)。シルク表記は「HVS / HYVISION SYSTEM」「REV.C」。Kintex-7を載せた基板で、公式のSDKやサンプルはほぼ無い。このリポジトリでは「K7-160T-DP」と呼んでいる。

## 主要部品

| 項目 | 内容 | 確認方法 |
|---|---|---|
| FPGA | Xilinx Kintex-7 **XC7K160T-FFG676-1** | JTAGで認識(IDCODE `0x364c093`)。チップの刻印はヒートシンクに隠れて未確認 |
| DDR3 | Samsung **K4B2G1646F-BCK0** ×2(2Gbit x16 ×2 = 32bit / 512MB) | 2個とも刻印を確認 |
| コンフィグFlash | Micron **N25Q64**(64Mbit / 8MB、SPI) | openFPGALoaderで検出 |
| クロック | Y2 = 50.000MHz(FPGAピンD24につながる)、Y3 = 135.000MHz(接続先は未確認) | Y2はLEDの点滅周期を実測して確認 |
| 冷却 | ヒートシンク+ファン | 目視 |
| 外部I/F | PCIe(4レーンと記載)、DisplayPort、GPIO用TP 57点、JTAG | ベンダー資料。PCIe/DPは動作未確認 |

## FPGAリソース(XC7K160T)

| リソース | 数 |
|---|---|
| スライス | 25,350(SLICEL 16,600 + SLICEM 8,750) |
| Block RAM | 325 × 36Kb = 11,700Kb(約1.46MB) |
| DSP48E1 | 600 |
| ユーザーI/O | 400(HR 250 + HP 150) |
| GTXトランシーバ | 8 |
| MMCM / PLL / BUFGCTRL | 8 / 8 / 32 |
| その他 | XADC、DNA_PORT、PCIeハードブロック |

## I/Oバンク

| バンク | 種別 | 用途 |
|---|---|---|
| 12, 13, 14 | HR(最大3.3V) | GPIO用TP、クロック、LED、UART。Bank13/14は3.3Vを実測 |
| 15, 16 | HR | GPIO用TP 57点には含まれない |
| 32 | **HP(最大1.8V)** | GPIO用TP55〜58。**3.3V厳禁** |
| 33, 34 | HP | DDR3(SSTL15、1.5V) |

詳細は [pinout.md](pinout.md)。

## 電源

12Vを、次の**どちらか**の方法で供給する。

| 方法 | 内容 |
|---|---|
| コネクタJ4 | 相手側のコネクタは **Molex 2.5mmピッチ プリント基板用コネクタ ハウジング 02P(5264-02)**。左が12V、右がGND |
| PCIeスロット | **マイニング用のPCIeライザー**にボードを挿し、スロット経由で12Vを供給する |

| 項目 | 内容 |
|---|---|
| 入力 | 12V。J4は左が12V、右がGND(テスターで確認。左右はユーザーが確認した向きで、基板のどの方向に当たるかは未記録) |
| 基板上のレール(シルク表記) | +1.0V(L2付近)、+1.25V(U1付近、1117系LDO)、+1.5V(L6付近)、+2.5V(U5付近)、+3.3V(L3/D16付近) |
| レギュレータ | U7 は刻印から ISL85033IRTZ(2出力の降圧型)の可能性が高い |

コネクタJ4は基板の部品番号で、FPGAのパッケージピンJ4とは別物。必要電流は分かっていない。

## JTAG

JTAGは **1.8V系**(VREF実測約1.9V)。JTAGコネクタはディップスイッチ側から TMS, TDI, TDO, TCK, GND, VREF の順。書き込み器の作り方は [jtag.md](jtag.md) を参照。

## コンフィグFlashのバックアップ

書き込みテストの前に、出荷時のFlash全体(8MB)をJTAG経由で保存しておくことを勧める。

```sh
openFPGALoader -c ft232 --fpga-part xc7k160tffg676 --dump-flash --file-size 0x800000 backup.bin
```

出荷時のFlashには有効なXilinxビットストリームが書かれている(オフセット0x2C付近にsync word `AA 99 55 66`)。

## LED

LEDは縦4個×横3列で、合計12個(D2〜D14、D6は無い)。FPGAから制御できると確認できたのは **D5 = C21** だけ。

| 上から | 左列 | 中央列 | 右列 |
|---|---|---|---|
| 1 | D2 | D7 | D11 |
| 2 | D4 | D9 | D13 |
| 3 | D3 | D8 | D12 |
| 4 | D5 | D10 | D14 |

Bank12/13/14のGPIO 52点を同時にトグルしてもLEDは一つも反応しなかった。そのため、残り11個はGPIO用TPとは別の回路につながっている(接続先は未特定)。
